# BuchTech Super Intelligence Services Portfolio

A responsive, single-page portfolio website built with HTML and CSS. No build step or framework is required.

## Preview locally
Open `index.html` in a web browser.

## Deploy to GitHub / Render
Upload `index.html` to the same directory served by your web server. If using the existing Express server, make sure `express.static(...)` points to the directory that contains `index.html`.

## Update contact details
The email and WhatsApp link are included in the contact section of `index.html`.
